Що робити, якщо картка захищена паролем? ▼

• Якщо при спробі запису виникає NotAllowedError, на чипі активовано біт AUTH0 (сторінка 0x29 для NTAG213 або 0x83 для NTAG215) або спалені Lock Bits.

• Стандартні заводські паролі китайських Google-карток (`PWD` 4 байти): FF FF FF FF, 00 00 00 00, 12 34 56 78 або 55 55 55 55.

• Зняти пароль можна у додатку NFC Tools → Інше → Видалити пароль або NXP TagWriter перед записом тут.

3. Низькорівнева карта пам'яті NTAG21x (TLV + NDEF по сторінках)

Точний розподіл по 4 байти на сторінку (починаючи з User Memory Page 0x04). Системні сторінки 0x00–0x03 захищені від перезапису.
